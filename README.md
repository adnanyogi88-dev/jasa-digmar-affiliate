## 🚀 Tentang

**DIGMAR** (Jasa Digmar Affiliate) adalah website profesional untuk agensi digital marketing dan affiliate yang berbasis di Indonesia. Website ini dirancang untuk menampilkan layanan, portfolio, dan testimoni klien dengan desain modern dan responsif.

**Tagline:** *Solusi Digital Marketing & Affiliate Terpercaya*

## ✨ Fitur

- 🎨 **Desain Modern & Profesional** — UI/UX clean dengan glassmorphism, gradient, dan animasi halus
- 📱 **Fully Responsive** — Mobile-first design yang tampil sempurna di semua perangkat
- ⚡ **Performa Tinggi** — Pure HTML/CSS/JS tanpa framework berat
- 🎭 **Animasi Scroll** — Fade-in dan slide-up animations menggunakan Intersection Observer
- 📊 **Counter Animasi** — Statistik angka yang beranimasi saat terlihat di viewport
- 🎠 **Testimonial Slider** — Carousel dengan autoplay, swipe support, dan keyboard navigation
- 📞 **WhatsApp Float Button** — Tombol WhatsApp mengambang untuk kontak langsung
- 🔝 **Back to Top** — Tombol kembali ke atas yang muncul saat scroll
- 🍔 **Mobile Menu** — Hamburger menu dengan animasi smooth
- 🔍 **SEO Friendly** — Meta tags dan struktur HTML semantik

## 🛠️ Teknologi

## 🚀 Cara Menjalankan

1. Clone atau download repository ini
2. Buka `index.html` di browser favorit Anda
3. Atau gunakan live server:

```bash
# Menggunakan VS Code Live Server Extension
# Atau menggunakan Python
python -m http.server 8000

# Atau menggunakan Node.js
npx serve .
```
